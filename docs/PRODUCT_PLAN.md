# 土地バンク（自社版）プロダクト計画

> **決定事項（2026-10-02）**：株式会社ネットデータの「土地BANK」のような、地図型の土地探し・営業支援ツールを自社版として作る。
> 既存の土台（自社の土地登録・お客様専用ページでの紹介と反応の記録）は残し、地図とデータを中心に作り替えていく。

---

## 1. 何を作るか

住宅会社・工務店・不動産仲介会社の営業担当者が、**地図の上で「土地」と「その土地の判断材料」をまとめて見られる**ツール。

| 課題（土地BANK と同じ） | 解決のしかた |
|---|---|
| 土地情報を集めるのに時間がかかる | 物件・価格・学区・災害リスクを1枚の地図に集約する |
| 土地の良し悪しを説明しにくい | 学区・ハザード・用途地域・相場を重ねて見せる |
| 土地なし客の契約率が低い | 地図を見せながら提案し、お客様の反応まで追える |

### 土地BANK との違い（自社版で勝ちにいく点）

| | 土地BANK | 自社版 |
|---|---|---|
| 地図・物件・エリア情報 | ◎ | ○ → ◎（段階的に追いつく） |
| お客様への提案と反応の記録 | △（営業担当者が画面を見せる） | ◎ お客様専用ページ・「気になる／見送る」（実装済み） |
| PG の営業支援との組み合わせ | — | 研修・すご川くんの運用ノウハウと一緒に提供できる |

| 背景地図 | 国土地理院 地理院タイル | 無料 | 可（出典表示） | Google マップに切り替える場合は有料（従量課金） |
| 住所 → 緯度経度 | 国土地理院 住所検索 API | 無料 | 可 | |
| ハザード | ハザードマップポータル「重ねるハザードマップ」タイル | 無料 | 可 | 地理院タイルと同じ形式でそのまま重ねられる |
| 学区・用途地域・地価公示・取引価格・成約価格・学校・医療機関・将来推計人口 など | 国土交通省 不動産情報ライブラリ API | 無料 | 可 | **API キーの申請が必要** |

## 4. 最大の論点：物件情報をどう集めるか

土地BANK の価値の中心は「毎日更新される全国の物件情報」。ここだけはオープンデータがない。

| 案 | 内容 | メリット | リスク・課題 |
|---|---|---|---|
| A. 登録・提携型 | 利用企業（工務店・仲介会社）が自社の土地を登録し、利用企業どうしで共有する | 権利関係がきれい。自社土地・未公開土地が集まる | 立ち上げ期は件数が少ない |
| B. ポータルサイトから収集 | SUUMO・アットホーム・HOME'S などの公開物件を自動で集める | 件数が一気に増える | 各サイトの利用規約は商用目的の利用を禁じている。**法務確認なしには進められない** |
| C. 物件データの提供契約 | データ提供会社・不動産会社とデータ提供契約を結ぶ | 件数と権利の両立 | 費用・交渉が必要 |
| D. pg-core の既存データ | pg-core はすでにポータル物件を取り込んでいる（`properties` の SUUMO / at home / HOME'S / REINS 系カラム） | すぐ件数が出る | 独立アプリの方針と、データの権利・契約の整理が必要 |

**おすすめ**：A で始め（自社・提携先の土地＋オープンデータで地図の価値を出す）、並行して B〜D の法務・契約の確認を進める。
レインズ（REINS）のデータは会員規約で外部への転載が制限されているため、使う場合は特に確認が必要。

## 5. ロードマップ

| フェーズ | 内容 | 物件データの判断待ち？ |
|---|---|:-:|
| 0（完了） | 土台：認証・マルチテナント・土地登録・顧客・お客様専用ページ・ローカル環境・CI | — |
| 1 地図の土台 | 地図画面、住所検索、自社土地のピン表示、ハザード・学区・用途地域の重ね表示、測量、メモ | 不要 |
| 2 価格・相場 | 地価公示・取引価格・成約価格・坪単価、国勢調査、地図から土地を紹介 | 不要 |
| 3 物件の収集 | §4 で決めた方法で物件を取り込み、毎日更新・過去事例の蓄積を開始、提案資料 PDF | **必要** |
| 4 詳細データ | 公図、路線価 | 不要（作業量が大きい） |

並行して：ステージング環境の構築（AWS・ドメイン・暗号鍵の保管を決めたら着手）。

---

## 6. 決めること

1. 物件情報の集め方（§4）と、法務確認の担当
2. 背景地図：地理院地図（無料）で始めるか、最初から Google マップ（有料・ストリートビューあり）にするか
3. 不動産情報ライブラリ API キーの申請者（無料・申請制）
